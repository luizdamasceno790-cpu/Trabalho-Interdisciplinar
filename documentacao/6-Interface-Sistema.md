# 6. Interface do Sistema

## 6.1 Telas

A interface contempla os seguintes módulos:

- Login.
- Painel.
- Clientes.
- Cardápio.
- Pedidos e detalhe do pedido.
- Novo pedido.
- Promoções.
- Estoque.
- Receitas.
- Produção.
- Compras.
- Configurações.
- Etiqueta de pedido.

## 6.2 Usabilidade

As telas foram organizadas em uma estrutura lateral de navegação. Os formulários apresentam ações diretas, dados agrupados por contexto e mensagens de feedback.

## 6.3 Responsividade

O frontend utiliza componentes responsivos para possibilitar consulta e operação em diferentes tamanhos de tela.

## 6.4 Evidências capturadas

As telas foram validadas em execução local com frontend em `http://localhost:5173` e API em `http://localhost:3000`.

O documento de evidências inclui login, painel, pedidos, clientes, cardápio, promoções, estoque, receitas, produção, compras, configurações e 12 tabelas ou visões do banco de dados.
