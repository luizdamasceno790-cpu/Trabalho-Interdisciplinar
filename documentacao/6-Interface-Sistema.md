# 6. Interface do Sistema

## 6.1 Telas

A interface contempla os seguintes módulos:

- Login.
- Painel.
- Clientes.
- Cardápio.
- Pedidos e detalhe do pedido.
- Novo pedido.
- Promoções.
- Estoque.
- Receitas.
- Produção.
- Compras.
- Configurações.
- Etiqueta de pedido.

## 6.2 Usabilidade

As telas foram organizadas em uma estrutura lateral de navegação. Os formulários apresentam ações diretas, dados agrupados por contexto e mensagens de feedback.

## 6.3 Responsividade

O frontend utiliza componentes responsivos para possibilitar consulta e operação em diferentes tamanhos de tela.
